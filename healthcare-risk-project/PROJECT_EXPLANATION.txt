1. PROJECT OVERVIEW
-------------------
This project is a "Smart Healthcare Risk Prediction System" that predicts 
whether a patient has HIGH or LOW medical risk and estimates their annual 
medical cost in Indian Rupees (₹). It uses Machine Learning (Linear Regression) 
and a Neural Network (MLP — Multi-Layer Perceptron) trained on a real-world 
medical insurance dataset. The system is deployed as an interactive web 
application built with Streamlit.


2. DATASET USED
---------------
File: dataset/insurance.csv  (Kaggle — Medical Cost Personal Dataset)
Records: 1,338 patients
Columns:
  • age       — Age of the patient (18–64)
  • sex       — Gender (male / female)
  • bmi       — Body Mass Index (measure of body fat based on height/weight)
  • children  — Number of dependents covered by insurance
  • smoker    — Whether the patient uses tobacco (yes / no)
  • region    — Mapped to Indian regions (North, South, East, West India)
  • charges   — Medical cost billed by insurance (target variable, converted to ₹)

A derived column "risk" is created:
  → If charges > $15,000 → HIGH RISK (1)
  → Otherwise           → LOW RISK  (0)

3. DATA SCIENCE TECHNIQUES APPLIED
-----------------------------------

3.1  DATA COLLECTION & LOADING
     - The dataset is loaded from a CSV file using Pandas (pd.read_csv).
     - This covers the Data Science Lab topic of working with structured data.

3.2  DATA PREPROCESSING & CLEANING
     - Missing values are handled:
         • Numeric columns → filled with median
         • Categorical columns → filled with mode
     - This demonstrates data wrangling and data quality management.

3.3  FEATURE ENGINEERING
     - Categorical variables are encoded for model consumption:
         • sex → binary (male=1, female=0)
         • smoker → binary (yes=1, no=0)
         • region → one-hot encoded into 4 binary columns 
           (region_northeast, region_northwest, region_southeast, region_southwest)
     - A new target column "risk" is derived from the "charges" column using
       a threshold of $15,000.
     - This covers feature engineering and data transformation topics.

3.4  EXPLORATORY DATA ANALYSIS (EDA)
     The Jupyter notebook (notebooks/data_analysis.ipynb) performs:
     - Descriptive Statistics: mean, median, std, min, max using df.describe()
     - Data Visualization using Matplotlib and Seaborn:
         • Histograms — distribution of BMI, age, charges
         • Scatter plots — BMI vs charges, age vs charges
         • Box plots — smoker vs charges, region-wise comparison
         • Pie charts — smoker/non-smoker distribution
         • Heatmaps — correlation matrix of all numeric features
         • Bar charts — region-wise average costs
     - These cover Data Science Lab topics: data visualization, descriptive
       statistics, and exploratory data analysis.

3.5  STATISTICAL ANALYSIS
     - Correlation Analysis: Pearson correlation matrix computed to find
       relationships between variables (e.g., smoking is highly correlated
       with charges).
     - ANOVA Test: One-way ANOVA performed to test whether mean charges
       differ significantly across regions.
     - Hypothesis Testing: Statistical significance testing with p-values.
     - These cover the statistics and probability topics in the syllabus.

3.6  DATA SPLITTING
     - The dataset is split into Training (80%) and Testing (20%) sets using
       sklearn's train_test_split with random_state=42 for reproducibility.
     - This is a fundamental Data Science practice to evaluate model
       generalization and avoid overfitting.

3.7  FEATURE SCALING / NORMALIZATION
     - StandardScaler is applied to normalize all features to zero mean and
       unit variance before feeding them to the Neural Network.
     - Formula: z = (x - μ) / σ
     - This is essential because neural networks are sensitive to feature
       magnitudes, and scaling ensures faster and more stable convergence.

3.8  LINEAR REGRESSION (Supervised Learning — Regression)
     - A Linear Regression model is trained to predict the actual medical
       cost (charges) as a continuous value.
     - Model equation: ŷ = β₀ + β₁·age + β₂·bmi + β₃·children + ...
     - Evaluation metrics:
         • R² Score: measures how well the model explains variance (~0.78)
         • MAE (Mean Absolute Error): average prediction error in ₹
         • RMSE (Root Mean Squared Error): penalizes larger errors
     - This covers the Machine Learning / Regression topic in the syllabus.

3.9  MODEL EVALUATION & METRICS
     - For Classification (MLP):
         • Accuracy, Precision, Recall, F1-Score
         • Confusion Matrix (TP, TN, FP, FN)
         • Classification Report per class
     - For Regression (Linear Regression):
         • R², MAE, RMSE
     - The Streamlit app shows all these metrics on the "Model Performance" page.

3.10 MODEL PERSISTENCE
     - Trained models are saved using Joblib (.pkl files):
         • mlp_model.pkl — the neural network classifier
         • lr_model.pkl — the linear regression model
         • scaler.pkl — the fitted StandardScaler
         • feature_cols.pkl — list of feature column names
     - This allows the web app to load and use the models without retraining.

3.11 GEOSPATIAL / REGIONAL ANALYSIS
     - Region-wise statistics are computed and visualized.
     - An interactive map of India is displayed using Streamlit's st.map(),
       with markers on Delhi (North), Chennai (South), Kolkata (East), and
       Mumbai (West).
     - This covers geospatial data analysis topics.

4. NEURAL NETWORK — MLP (Multi-Layer Perceptron)
-------------------------------------------------

4.1  WHAT IS AN MLP?
     An MLP is a type of Artificial Neural Network (ANN) consisting of
     multiple layers of neurons (nodes). Each neuron applies a weighted sum
     of inputs, adds a bias, passes the result through an activation function,
     and forwards it to the next layer. The network "learns" by adjusting 
     weights and biases to minimize a loss function.

4.2  ARCHITECTURE OF OUR MLP
     ┌──────────────┐
     │  INPUT LAYER │  9 neurons (one per feature)
     │  (9 features)│  age, bmi, children, sex, smoker, 4 region dummies
     └──────┬───────┘
            ↓
     ┌──────────────┐
     │ HIDDEN LAYER │  64 neurons, ReLU activation
     │     1 (64)   │  
     └──────┬───────┘
            ↓
     ┌──────────────┐
     │ HIDDEN LAYER │  32 neurons, ReLU activation
     │     2 (32)   │  
     └──────┬───────┘
            ↓
     ┌──────────────┐
     │ HIDDEN LAYER │  16 neurons, ReLU activation
     │     3 (16)   │  
     └──────┬───────┘
            ↓
     ┌──────────────┐
     │ OUTPUT LAYER │  1 neuron, Sigmoid activation
     │   (1 class)  │  Outputs: probability of HIGH RISK
     └──────────────┘

     Total parameters: (9×64+64) + (64×32+32) + (32×16+16) + (16×1+1) = 3,345

4.3  KEY NEURAL NETWORK CONCEPTS USED

     a) ACTIVATION FUNCTION — ReLU (Rectified Linear Unit)
        • Formula: f(x) = max(0, x)
        • Used in all hidden layers.
        • Solves the vanishing gradient problem.
        • Introduces non-linearity so the network can learn complex patterns.

     b) OPTIMIZER — Adam (Adaptive Moment Estimation)
        • Combines advantages of AdaGrad and RMSProp.
        • Adapts learning rate for each parameter individually.
        • Faster convergence and more stable training.

     c) LOSS FUNCTION — Log-Loss (Binary Cross-Entropy)
        • Formula: L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
        • Measures how far predicted probabilities are from actual labels.
        • Final training loss achieved: ~0.23

     d) BACKPROPAGATION
        • The algorithm that computes gradients of the loss with respect to
          each weight using the chain rule of calculus.
        • Gradients flow backward from the output layer to the input layer.
        • Weights are then updated: w = w - α·(∂L/∂w)

     e) LEARNING RATE (Adaptive)
        • Initial learning rate: 0.001
        • Uses adaptive schedule — reduces automatically when validation
          loss plateaus, preventing overshooting.

     f) EARLY STOPPING
        • Training stops automatically if the validation loss does not
          improve for 20 consecutive iterations (n_iter_no_change=20).
        • Prevents overfitting by not training longer than necessary.
        • Validation fraction: 15% of training data held for validation.

     g) FEATURE SCALING (StandardScaler)
        • Neural networks require normalized input for stable training.
        • All 9 features are scaled to mean=0, std=1 before being fed 
          into the network.

     h) REGULARIZATION (L2 / Weight Decay)
        • alpha=0.0001 adds a penalty term to the loss function:
          L_total = L_data + α·||w||²
        • Prevents weights from growing too large, reducing overfitting.

4.4  TRAINING PROCESS
     1. Forward Pass: Input features pass through all layers to produce a prediction.
     2. Loss Calculation: Compare prediction with actual label using log-loss.
     3. Backward Pass (Backpropagation): Compute gradients for all weights.
     4. Weight Update: Adam optimizer updates weights using computed gradients.
     5. Repeat for up to 2,000 iterations (epochs) or until early stopping triggers.

4.5  MODEL PERFORMANCE
     • Accuracy: ~93.66% (on test set)
     • Precision (High Risk): 100% — no false alarms
     • Recall (High Risk): ~78% — catches majority of high-risk patients
     • F1-Score: ~0.88
     • Final Training Loss: ~0.23
     • The loss curve (visible in the app) shows smooth convergence.
